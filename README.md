# Guide Marche Nordique – Sologne

Appli web (PWA) des circuits de marche nordique : carte, guidage GPS et vocal.
Les circuits sont lus dans Supabase ; `admin.html` (connexion requise) permet de les corriger et d'ajouter des marches par import GPX.
Voir `docs/conception.md` et `supabase/schema.sql`.
